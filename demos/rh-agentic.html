How it works

the short version

A language model does the thinking. Plain code decides whether any of it is allowed to happen.

1

It looks

Every morning it sweeps the market for names worth a second look, and keeps a running memory of the ones that are moving.

2

It reads

Anything promising gets a full written work-up — including an argument for why the idea is wrong. No write-up, no trade.

3

It scores

The work-up becomes a single number. Under the bar, nothing happens, however good the story sounds.

4

Code decides

Every order hits one deterministic gate that the model cannot argue with. If the gate says no, it is no — and the refusal is recorded.

5

It learns

Anything that gets through is protected the moment it opens, then graded afterwards. What is learned changes the scoring — and only evidence can change it.

That is the outline, not the machine

The real thing has considerably more going on underneath — how candidates are actually sourced, what the gate really checks, and how the model rewrites itself. Those stay private.
