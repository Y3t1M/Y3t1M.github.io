WHAT THIS IS

An autonomous trading agent that has to earn every order

RH Agentic runs a small swing-trading account on Robinhood's agentic API. A language model does the reading and the reasoning; rules written in plain code decide whether an order is allowed. This is what its home screen looks like, on an account that doesn't exist.

Why no trade

THE RULES DECIDE, NOT THE MODEL

Every candidate the model likes still has to pass a rules engine. A DENY is final and gets logged like a trade, so the rules are measured, not just obeyed.
